# User Service

## Описание проекта

Консольное приложение `user-service`, разработанное в рамках курса "Интенсив Java".

Цель проекта — реализовать CRUD-операции для сущности User с использованием Hibernate и PostgreSQL без применения Spring Framework.

Технологии:
- Java
- Maven
- Hibernate ORM
- PostgreSQL
- JDBC
- Log4j / SLF4J

Требования:

- Использовать Hibernate в качестве ORM.
- База данных — PostgreSQL.
- Настроить Hibernate без Spring, используя hibernate.cfg.xml или properties-файл.
- Реализовать CRUD-операции для сущности User (создание, чтение, обновление, удаление), которая состоит из полей: id, name, email, age, created_at.
- Использовать консольный интерфейс для взаимодействия с пользователем.
- Использовать Maven для управления зависимостями.
- Настроить логирование.
- Настроить транзакционность для операций с базой данных.
- Использовать DAO-паттерн для отделения логики работы с БД.
- Обработать возможные исключения, связанные с Hibernate и PostgreSQL

## Предметная область

Проект представляет собой сервис управления пользователями.

Сущность User описывает зарегистрированного пользователя системы и содержит информацию:
- имя;
- email;
- возраст;
- дату создания записи.

Сервис поддерживает базовые операции управления пользователями (CRUD).
